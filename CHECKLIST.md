# ✅ Checklist de Setup

Use este checklist para garantir que tudo está configurado corretamente.

## Antes de começar

- [ ] Node.js instalado (v18 ou superior)
- [ ] npm instalado
- [ ] Conta Google (para API do Gemini)

## Setup inicial

- [ ] ✅ Projeto criado (já feito!)
- [ ] ✅ Dependências instaladas (`npm install`)
- [ ] Chave da API Gemini obtida em https://makersuite.google.com/app/apikey
- [ ] Arquivo `.env` editado com a chave `GEMINI_API_KEY=...`
- [ ] Servidor de desenvolvimento rodando (`npm run dev`)
- [ ] Aplicação acessível em http://localhost:5173

## Testando localmente

- [ ] Página carrega sem erros
- [ ] Mensagem de boas-vindas aparece
- [ ] Campo de texto está funcional
- [ ] Consegue enviar uma mensagem
- [ ] Chatbot responde em inglês
- [ ] Correções aparecem quando há erros
- [ ] Botão "Clear Chat" funciona
- [ ] Interface responsiva em mobile (testar redimensionando o navegador)

## Deploy (opcional)

- [ ] Conta criada no Vercel
- [ ] Repositório GitHub criado e código enviado
- [ ] Projeto conectado no Vercel
- [ ] Variável de ambiente `GEMINI_API_KEY` configurada no Vercel
- [ ] Deploy bem-sucedido
- [ ] Aplicação funcionando na URL do Vercel
